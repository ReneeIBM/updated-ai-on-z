IBM Z Accelerated SnapML

AI Lifecycle: Prepare Data · Train Model

Snap ML is an IBM library developed and maintained by IBM Research that provides high-speed training and inference of popular machine learning models. It is fully compatible with the scikit-learn Python API and addresses the core ML needs of data scientists: speed, resource efficiency, accuracy, and scalability to TB-scale datasets.

What Snap ML Supports

  • Generalized Linear Models, Tree-based Models, and Gradient Boosting Machines
  • Accelerated scoring of scikit-learn, XGBoost, and LightGBM trained models when exported to PMML, JSON, or ONNX
  • Drop-in scikit-learn compatible API — no code changes required
  • Scalable to TB-scale datasets

IBM Telum Integrated Accelerator for AI

Starting with Snap ML version 1.9.0, Snap ML can utilize the IBM Integrated Accelerator for AI. Accelerator exploitation can be enabled at model import time for:

  • Random Forest
  • Extra Trees
  • Gradient Boosting Machines

Starting with Snap ML 1.9.1, SnapML-trained tree-based models (RF, ET, and GB) can be exported to PMML.

Getting Started

IBM Snap ML is available as part of Machine Learning for z/OS, as well as for IBM LinuxONE and Linux on Z (including z/OS Container Extensions). Container images are available in the IBM Z and LinuxONE Container Image Registry under ibmz-accelerated-for-snapml. Snap ML can also be installed directly via PyPI:

pip install snapml

IBM Z Accelerated for TensorFlow

AI Lifecycle: Train Model · Deploy Models

TensorFlow is an open source machine learning framework with a comprehensive set of tools that enable model development, training, and inference — including a rich and robust ecosystem. IBM Z Accelerated for TensorFlow runs on Linux on IBM Z and LinuxONE, including z/OS Container Extensions.

IBM Telum Integrated Accelerator for AI

On IBM z16, LinuxONE 4, and later machines (including z/OS Container Extensions), TensorFlow core Graph Execution leverages inference acceleration that transparently targets the IBM Integrated Accelerator for AI through the IBM Z Deep Neural Network (zDNN) library. This support extends to the Telum II processor on IBM z17. No changes to the original model are needed to take advantage of this acceleration.

TensorFlow Serving

With TensorFlow Serving, you can expose REST and gRPC endpoints for model inference requests, supporting high-throughput, low-latency inference serving on IBM Z and LinuxONE.

ONNX & IBM Z Deep Learning Compiler

AI Lifecycle: Optimize Model · Deploy Models

ONNX (Open Neural Network Exchange) establishes a streamlined path from playground to production. You can start a project using frameworks like PyTorch or TensorFlow, train on any platform, then export to ONNX and deploy anywhere. On IBM Z, the IBM Z Deep Learning Compiler (zDLC) — based on ONNX-MLIR — compiles ONNX models to optimized s390x binaries, automatically offloading eligible operations to the IBM Integrated Accelerator for AI.

IBM Research enhanced zDLC to target the Telum Integrated Accelerator for AI for a variety of ONNX primitives. This support has been contributed upstream to ONNX-MLIR, which has been updated to support the Telum II processor in IBM z17.

Getting Started — by Platform

z/OS users can use an MLz-based approach or Linux on Z options via z/OS Container Extensions:

  • Machine Learning for z/OS (MLz) — Upload your ONNX model and compile and deploy at the push of a button. Supports server-side mini-batching for ONNX/DLC model serving and native CICS, IMS, and Java scoring services.

Linux on Z, zCX, and LinuxONE users can use zDLC directly to create model programs for serving environments or applications:

  • Available through the IBM Z and LinuxONE Container Registry (listed as zDLC)
  • Command-line compiler producing a .so library with optional Java and Python wrappers
  • Model libraries can be used directly or via Triton Inference Server

Converting Models to ONNX

Converting or exporting trained deep learning models to ONNX is a requirement for using zDLC:

  • TensorFlow — Use the open-source tensorflow-onnx package
  • PyTorch — Export directly using PyTorch's built-in ONNX export APIs
  • Other frameworks — See the ONNX community page

Best practice: Convert models to ONNX on the platform on which they were trained to avoid endian issues (e.g., convert on x86 before transferring to IBM Z).

Converting Models to PMML

PMML (Predictive Model Markup Language) is used for traditional ML models. Machine learning models in PMML format can be leveraged by IBM Snap ML — tree-based models can utilize the IBM Integrated Accelerator for AI. Machine Learning for z/OS also supports PMML model deployment.

The recommended approach is sklearn2pmml, which allows creating a PMMLPipeline object containing scikit-learn, XGBoost, or LightGBM models:

from sklearn2pmml import PMMLPipeline, sklearn2pmml
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=200, max_depth=6)
pipeline = PMMLPipeline([("model", model)]).fit(X_train, y_train)
sklearn2pmml(pipeline, "model.pmml", with_repr=True)
