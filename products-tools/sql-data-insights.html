What is SQL Data Insights Pro?

IBM SQL Data Insights Pro adds AI-powered semantic understanding directly inside Db2 for z/OS. It lets you query your data by meaning — finding similarities, patterns, and relationships that traditional SQL can't easily surface — using standard SQL syntax you already know. All processing happens on-chip via Telum AI acceleration, with no data leaving Db2 and no external infrastructure required.

Why Use It on IBM Z

  • Zero data movement — Embedding models and inference run entirely inside Db2 on z/OS. Sensitive enterprise data never leaves the platform.
  • No new infrastructure — Runs on existing IBM Z hardware using Telum on-chip AI acceleration. No GPU, no separate ML cluster.
  • SQL you already know — Query by similarity and meaning using standard SQL syntax. No Python, no vector database, no new query language.
  • Works on structured and unstructured data — Analyze relational columns and free-text fields like comments, descriptions, and logs within the same query.
  • Faster time to insight — Bypass the typical extract → move → process → return pipeline. Answers come from data where it already sits.
