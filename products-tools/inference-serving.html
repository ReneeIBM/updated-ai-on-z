AI Lifecycle: Serve Model

Triton Inference Server is a model server open-sourced by NVIDIA. Triton Inference Server's primary business value lies in its ability to standardize enterprise AI deployment by running models from any framework — such as PyTorch, TensorFlow, or ONNX Runtime — on a single, unified platform. By maximizing hardware utilization through dynamic batching and concurrent model execution, it significantly cuts compute costs while delivering low-latency predictions. This flexibility and resource efficiency streamline MLOps workflows, allowing teams to scale high-throughput AI services in production without maintaining fragmented infrastructure.

It is commonly used across a wide variety of platforms and architectures, including s390x (Linux on Z). On Linux on Z, Triton can leverage AI frameworks that take advantage of both the SIMD architecture and the IBM Integrated Accelerator for AI (Neural Network Assist — NNPA).

Triton Inference Server is a component of the AI Toolkit for IBM Z and LinuxONE, with container images available in the IBM Z and LinuxONE Container Image Registry.

Key Features

  • Server-side micro-batching (Dynamic Batching) for throughput optimization
  • Support for multiple frameworks and model backends
  • Model version control and concurrent model execution
  • Metrics/Monitoring integration
  • Supports customization: new frameworks, rule integrations

Supported Model Paths on IBM Z

Triton Inference Server is quite flexible and supports a wide variety of model types. It also has the ability to create custom model backends, which make it extremely flexible for a variety of scenarios. In our testing, we have focused on three primary paths which allow us to deploy models that can leverage the Integrated Accelerator for AI when deployed on Telum I and Telum II processors:

  • Traditional ML models in PMML, ONNX, or JSON format, run using an IBM Snap ML C++ runtime
  • Deep learning models in ONNX format compiled with the IBM Z Deep Learning Compiler (zDLC)
  • PyTorch backend with Telum II support — enables real-world multi-model AI use cases on Telum II

Getting Started

Triton Inference Server is a component of the AI Toolkit for IBM Z and LinuxONE. The AI Toolkit for IBM Z and IBM LinuxONE is designed to enable our clients to deploy and accelerate the adoption of popular open source AI frameworks on their z/OS® and IBM® LinuxONE platforms. The AI Toolkit follows a rigorous IBM Secure Engineering process that vets and scans open source AI-serving frameworks and IBM-certified containers for security vulnerabilities and validates compliance with industry regulations. Clients can also purchase IBM Elite Support for AI Toolkit for IBM Z and LinuxONE. These components of AI Toolkit for IBM Z and LinuxONE are freely available.

Two channels are provided for customers to download and deploy Triton Inference Server for LinuxONE:

  • IBM Z Accelerated for Triton™ Inference Server in Red Hat Ecosystem Catalog
  • IBM Z and LinuxONE Container Image Registry — instructions for downloading IBM Z Accelerated for Triton Inference Server from ICR

IBM has made detailed examples available that can be used to try the Snap ML backend on Triton Inference Server:

  • Snap ML backend examples on GitHub
  • Triton Deep Learning Compiler backend (ONNX + zDLC)

Note that IBM Snap ML is available for install via PyPI, while the IBM Deep Learning Compiler is available via the IBM Z and LinuxONE Container Repository. Both are no-charge sources.

AI Lifecycle: Serve Model

Red Hat AI Inference Server is Red Hat's enterprise-supported model serving platform for large language models and foundation models, built on vLLM and designed to run on Red Hat OpenShift. It exposes an OpenAI-compatible API, making it a drop-in serving layer for applications already built against OpenAI's interfaces. It is aimed at platform teams and ML engineers who need to run LLM inference in production on OpenShift — with enterprise support, a defined release lifecycle, and operational tooling — rather than managing a raw vLLM deployment themselves. On IBM Z and LinuxONE, Red Hat AI Inference Server brings production GenAI serving to mission-critical on-premises infrastructure, including Spyre-accelerated workloads on IBM z17.

Key Capabilities

  • OpenAI-compatible Chat Completions and Completions API — no client-side re-engineering required
  • Enterprise support, CVE patching, and defined release lifecycle from Red Hat
  • Deploys through the Red Hat OpenShift AI operator with built-in health probes, scaling, and service mesh integration
  • Spyre Accelerator support on IBM z17 for hardware-accelerated LLM inference on the mainframe
  • Supports IBM Granite, Llama, Mistral, and other open-weight models compatible with vLLM
  • Consistent runtime across on-premises OpenShift on IBM Z and cloud OpenShift environments

On IBM Z

Red Hat AI Inference Server is a Serve Model tool. Within the Red Hat OpenShift AI stack on IBM Z and LinuxONE, it is the default serving runtime for LLM and foundation model workloads — the component that actually handles inference requests once a model is deployed. Organizations building generative AI capabilities on IBM Z should consider it when they need a production-grade, operator-managed LLM serving layer that integrates with OpenShift's existing observability, scaling, and security tooling. For traditional ML model serving on OpenShift on Z alongside LLM workloads, pair it with IBM Z Accelerated for Triton.
