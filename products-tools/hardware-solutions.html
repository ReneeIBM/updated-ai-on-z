IBM Integrated Accelerator for AI (Telum)

What is the IBM Integrated Accelerator for AI?

The IBM Integrated Accelerator for AI is an on-chip AI accelerator available on the IBM Telum chip — part of IBM z16, LinuxONE 4, and now IBM z17 (Telum II) servers. It is designed to enable high throughput, low latency inference for deep learning and machine learning.

You can build and train your models on any platform, including IBM Z. When you are ready to deploy, your models receive transparent acceleration and optimization on-chip, leveraging the best available acceleration for the model type.

The IBM Integrated Accelerator for AI is more than just a matrix multiply accelerator — it provides optimization and acceleration for a wide set of complex functions commonly found in deep learning and machine learning models, enabling a broader set of operations to run on-chip.

Why the Integrated Accelerator?

  • On-chip, no GPU required — AI inference runs directly on the Telum processor alongside your business transactions, with no external hardware needed.
  • High throughput, low latency — Designed for real-time scoring at enterprise scale, enabling AI decisions within transaction flows.
  • Transparent acceleration — Supported frameworks automatically offload eligible operations to the accelerator — no model rewriting required.
  • Security and compliance — Data never leaves the IBM Z platform, preserving the security and governance properties of your enterprise environment.

Using the Integrated Accelerator for AI

Depending on your model type, there are a few essential approaches to leveraging the Integrated Accelerator for AI. These capabilities are available in IBM product offerings as well as through no-cost channels (such as the IBM Z Container Image Registry).

For deep learning models (PyTorch, TensorFlow):

  • ONNX models compiled with the IBM Z Deep Learning Compiler (zDLC)
  • IBM Z Accelerated for TensorFlow — transparent zDNN offload
  • IBM Z Accelerated for PyTorch — Telum I and II acceleration

For traditional ML models (scikit-learn, XGBoost, LightGBM):

  • IBM Snap ML — optimized training and inference with Telum acceleration for Random Forest, Extra Trees, and Gradient Boosting

For framework and compiler developers:

  • IBM zDNN — the low-level C library exposing Telum AI accelerator operations. Available in z/OS in all in-service releases, and for RHEL, Ubuntu, and SUSE.

IBM Spyre Accelerator

AI Lifecycle: Deploy Models · Serve Model

The IBM Spyre Accelerator is a system-on-a-chip PCIe card purpose-built to bring generative AI and large language model inferencing to IBM Z. Compatible with IBM z17, it slots directly into the IBM Z system alongside the existing Telum processor, adding dedicated AI compute optimized for the matrix and vector operations that dominate LLM and foundation model workloads. Spyre evolved from IBM Research's AIU prototype — expanding from the single on-chip accelerator core in Telum to 32 individual accelerator cores per card, with cards clusterable for up to 256 cores per system. It is designed for organizations running IBM Z who need to deploy generative AI — LLMs, RAG applications, intelligent assistants — entirely within their existing on-premises infrastructure, without shipping data to an external cloud or GPU cluster. The problem it solves is real: roughly 70% of the world's transactions by value run through IBM mainframes, and until Spyre, running LLM-class AI on that data meant moving it somewhere else. Spyre changes that.

Key Capabilities

  • 32 AI accelerator cores per PCIe card; cluster up to 8 cards for 256 cores on a single IBM Z system
  • 25.6 billion transistors on 5 nm node process — purpose-built for AI compute patterns, not general-purpose CPU
  • Supports FP16 (default), INT8, and INT4 precision; GPTQ quantization (W4A16) for reduced memory footprint
  • Tensor-parallel inference across multiple cards for large model support
  • Online serving (OpenAI-compatible API) and offline batch inference via vLLM and the vllm-spyre plugin
  • Supports IBM Granite, Llama, Mixtral, and other decoder-only transformer and encoder/embedding model architectures
  • Accessed through software platforms — no direct programming required after firmware configuration

On IBM Z

Spyre covers the Deploy Models and Serve Model stages — specifically for generative AI and LLM workloads on IBM z17. It complements the Telum integrated accelerator, which handles real-time transactional AI (fraud detection, credit scoring) at transaction speed. Spyre handles a different class of workload: large foundation model inference, RAG, code modernization, and enterprise assistants — use cases that require sustained compute over larger models, not millisecond in-transaction scoring. Organizations in regulated industries where data cannot leave IBM Z, but who still need LLM-class AI capabilities, should evaluate Spyre as the hardware foundation for their generative AI strategy on the mainframe. After firmware configuration, workloads run through compatible software platforms:

  • IBM watsonx.ai
  • Red Hat OpenShift AI
  • Red Hat AI Inference Server (via vllm-spyre plugin)
  • IBM Z Database Assistant · IBM watsonx Assistant for Z
